# Auto PDF Merger 📄

A simple Python automation project that merges multiple PDF files into a single PDF using the `pypdf` library.

## Features
- Automatically scans a folder for PDF files
- Merges multiple PDFs into one file
- Simple and beginner-friendly
- Lightweight and fast

## Technologies Used
- Python
- pypdf
- os module
